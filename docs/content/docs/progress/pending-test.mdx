# 待测试确认

- [ ] 质量门禁执行后端测试与 Vet、前端应用/测试类型检查、Bun 测试和 Next.js 构建；任一步失败时不得发布 Docker 镜像。
- [ ] 图片模型显式配置图生图路由为 `generations` 时，画布节点参考图以 JSON `image` 发送，单图为字符串、多图为数组；`auto` 仍按原协议走 multipart edits。
- [ ] 批量图片生成全部失败时，画布显示第一条真实上游错误，不再只显示“全部图片生成失败”。
- [ ] 生成请求在调用上游前原子预留积分并创建任务；上游失败自动退款，并发请求不会把余额扣成负数，重复异步失败只退款一次。
- [ ] 被禁用或已删除用户的旧 JWT 无法继续访问；生成、代理、临时上传和上游响应均受配置大小上限约束。
- [ ] 旧画布无版本文档可升级到当前版本；云端并发编辑返回冲突并保留本地副本，快速切换账号不会把旧账号画布保存到新账号。
- [ ] 新站点没有 `TenantApiConfig` 记录时仍可从渠道模型目录加载全部能力；v0.5 旧 `/api-config` 写入口在同一事务内双写旧记录和规范化目录，并返回将在 v0.6 只读的弃用提示。
- [ ] 旧数据库升级后，渠道、模型能力、图片/视频路由、视频时长和已加密 API Key 会幂等投影到规范化模型服务；重复启动不新增记录或递增修订，无效旧 JSON 记录迁移问题且不阻塞其它配置。
- [ ] 模型详情以一个保存动作原子更新公开身份、上游模型 ID、操作合同、渠道定价覆盖和审计；并发修订冲突不覆盖新数据，任一步失败不留下部分配置。
- [ ] 渠道默认协议可由模型操作继承，模型覆盖协议优先生效；新同步模型保持待配置，上游缺失模型只标记不删除，旧启用模型保留可用并显示待复核。
- [ ] 模型 API 配置导出保持加密 envelope `version: 1`，内部 payload 使用 `schema_version: 2` 并往返保留公开身份、协议默认值、操作合同、规范化定价和智能路由；旧 payload v1 仍可导入。
- [ ] 模型目录支持渠道视角和模型视角；未保存草稿可直接测试，定价页正确区分全局默认价与渠道覆盖价，导入成功后刷新渠道、模型、定价和路由数据。
- [ ] 管理后台信息提示使用独立信息色，不再因黑白主色导致 `/admin/api-config` 智能路由说明块显示为深灰底。
- [ ] 物理、智能路由池和合并组模型选择解析为结构化身份；智能路由请求使用 `routing_pool_id`，不再用 `channel_id=0 + model` 隐式聚合候选；图片真实生成和管理后台模型测试对同一路由生成相同 method、path、Content-Type 和参考图载荷。
- [ ] 登录 / 注册 / 个人中心流程在当前商用部署中可正常使用。
- [ ] 空数据库首次启动且已配置 `INIT_ADMIN_*` 时，会自动创建初始管理员。
- [ ] 未登录访问首页显示落地页，登录后进入业务工作区。
- [ ] 未登录首页展示更完整的商业化落地页，包括能力、场景、积分和后台统一配置说明。
- [ ] 普通用户不可见管理后台入口，也不可访问管理接口。
- [ ] 管理员在 `/admin/api-config` 可为每个视频模型单独指定接口路由。
- [ ] SuperAdmin 可在 `/admin/api-config` 使用密码加密导出全局渠道、渠道 API Key、模型能力与路由、当前租户定价、合并组、自定义视频配置预设和智能路由池；导出文件不得明文暴露任何配置内容，错误密码或被篡改文件无法导入。
- [ ] 导入模型 API 配置时先显示新增、更新、跳过预览；确认后合并配置但不删除目标环境额外数据，多个不同名称的渠道可共用同一 Base URL 并在重复导入时按“名称 + Base URL”更新；文件内非空 API Key 覆盖匹配渠道，同名异址、重复名称/组合键/引用和缺少密钥的新渠道及其依赖配置应跳过并显示原因。
- [ ] 视频模型未显式指定路由时默认走 `/v1/videos`，不再仅凭模型名自动切到 `xai` 或 `newapi` 分支。
- [ ] 画布或视频工作台使用 XAI 单张参考图生成竖屏视频时，请求应携带 `aspect_ratio`，生成结果应符合竖屏比例。
- [ ] 智能路由视频池只包含同一规范化协议合同的物理模型；选择 `9:16` 时，各视频协议应发送对应的竖屏字段，不得因故障切换到不同协议生成 `16:9`。
- [ ] 渠道可切换到“炳火 API 标准”；直接渠道、合并组和智能路由均应使用固定比例/清晰度及 `/v1/video/generations` 请求，请求体同时携带同值的 `ratio` 和 `aspect_ratio`，支持普通参考图、首尾帧、参考视频和参考音频，且智能路由不跨 API 标准或协议合同切换。
- [ ] 视频生成完成后，上游成片即使以 `application/octet-stream` 或空 MIME 返回，只要内容是 MP4/WebM，也应被保存为可播放视频；炳火 `result_url` 签名直链应优先通过 Next.js 代理下载转存，代理失败时恢复直接播放兜底。
- [ ] 视频生成遇到非余额类上游错误时，视频工作台和画布视频节点应显示上游原文并给出操作引导；代理返回 `{"ok":false,"error":"..."}` 时也应提取错误原文；上游余额/额度不足仍不得暴露真实额度、请求 ID 或上游原文。
- [ ] 炳火视频上游返回 `{"ok":false,"error":"..."}` 等非余额错误时，用户接口应返回可解析的 `{code,msg,error_detail}`，不得因透传上游响应头触发 Cloudflare 520。
- [ ] 超级管理员可在管理概览配置全局公告；启用后用户访问时弹出，勾选“本次更新前不再弹出”后同版本不再弹，公告更新后应再次弹出。

- [ ] 管理后台的渠道列表、模型目录、智能路由和模型调用日志中，鼠标移到渠道名称上应显示该渠道备注；渠道列表同时在 Base URL 下显示备注，长备注截断且未填写时不显示空占位。
- [ ] 管理员在 `/admin/model-logs` 失败详情中可查看实际上游请求 URL、Content-Type 和请求体；本地校验失败应显示未向上游发送，请求体关键词可被筛选命中。
- [ ] 管理员在 `/admin/model-logs` 可切换查看失败、成功或全部模型调用日志；成功日志详情也应显示实际上游请求 URL、Content-Type 和完整请求体，JSON 请求体不得被改写或截断。
- [ ] 管理员在 `/admin/model-logs` 可查看模型失败日志，失败渠道应显示渠道名或渠道 ID，并可按模型、用户、类型和关键词筛选。
- [ ] 默认标准视频请求和 `yijia` 路由都应按 `/v1/videos` JSON 格式提交 `model`、`prompt`、`size` 和字符串 `input_reference`；混合渠道、旧画布节点或原始模型名也不得误走 multipart `input_reference[]`、`resolution_name`、`preset` 请求。
- [ ] 管理员在 `/admin/api-config` 可为每个视频模型单独配置可选时长；前台视频时长面板应只显示后台允许的选项。
- [ ] 管理员在 `/admin/api-config` 可仅对自定义视频配置的六个媒体角色设置“必填”，模型和预设快照应保留该状态；所有媒体可选时，视频工作台和画布可仅凭提示词使用标量默认值生成，空的可选媒体角色不应写入上游请求；存在缺失的必填角色时应在请求前显示对应中文提示，画布首次生成与重试应发送一致的角色参数。
- [ ] 管理员在 `/admin/api-config` 可为每个视频模型配置超过旧固定上限的媒体数量，且视频工作台和画布会按配置数量限制素材。
